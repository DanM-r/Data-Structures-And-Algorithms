# Data Structures And Algorithms

A simple CLI program made in Rust that allows to test and visualize data
structures and algorithms.

## List of Features

Currently on development, but for the first version of this program will have
the menu and general system to work with data structures and algorithms.

### Data structures

The first data structure to be implemented wil be the red-black tree with their
basic operators and performance statistics.
